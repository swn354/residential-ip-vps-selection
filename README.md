## 先把五个概念分清：原生 IP 不等于住宅 IP

这两个词被混用得最厉害。原生 IP 解决的是“注册国和机房所在国一致”，住宅 IP 解决的是“这个 IP 在谁名下”。一台美国机房里的美国原生 IP，地理位置完全正确，ASN 依然可能是某家云厂商，风控照样认得出。

| 类型 | ASN 归属 | 解决什么 | 风控表现 |
| --- | --- | --- | --- |
| 数据中心 IP | AWS、Google、Linode 等云厂商 | 不解决，它就是一台机器 | 最容易被标记，限流封号高发 |
| 原生 IP（Native） | 可能是机房，但注册国与机房国一致 | 地理位置对不对 | 比广播 IP 稳，仍不具住宅身份 |
| 广播 IP（BGP 广播） | A 国 IP 段广播到 B 国机房使用 | 低成本拿一个“当地 IP” | 严格平台可能识别为异常 |
| 住宅 IP | 真实 ISP，如 Comcast、AT&T、BT | 像不像普通家庭用户在上网 | 平台认可度最高 |
| 双 ISP 住宅 IP | 同时绑定两个不同家宽运营商 | 冗余度与纯净度 | 被判为机房的概率更低 |

判断标准可以记成一句：**住宅优先，双 ISP 更好，原生只是及格线，数据中心 IP 别拿去跑对 IP 敏感的业务**。还有个中间状态值得提一句——商业宽带 IP，比纯机房好看一点，但在严格风控面前照样露馅，别把它当住宅用。

## 下单前必查的五项

### 1. IP 纯净度：查 ASN，不看商家形容词

拿商家给的测试 IP，去 ipinfo.io 看 ASN 和公司名，去 scamalytics 看风险评分，再用 pingip.cn 交叉一遍。合格的信号很明确：ASN 归属显示为当地宽带运营商，类型标注是 Residential 或具体家宽品牌，而不是 Hosting、Data Center；风险评分越低越好。

顺带一个判断商家底气的办法：敢在页面上公开测试 IP 让你自己查的，通常对 IP 质量有把握；只写“原生住宅、纯净解锁”却拿不出测试 IP 的，先打个问号。

### 2. 回程线路：缩写对应的是完全不同的场景

| 线路 | ASN | 适用判断 |
| --- | --- | --- |
| CN2 GIA | AS4809 | 电信用户为主、预算充足、要国内方向最稳 |
| CUII | AS9929 | 联通精品网，质量接近 CN2 GIA，价格更友好 |
| CMIN2 | AS58808 | 移动用户为主 |
| 4837 | AS4837 | 便宜，晚高峰可能波动 |
| 国际 BGP | — | 业务本身面向海外，自备中转 |

看到“9929”“CN2 GIA”这类字样，要确认它标的是回程还是去程，以及是不是全程走这条线。同样是英国住宅产品，有的商家明写走国际 BGP、不保证国内方向稳定，建议自备中转；有的标 9929 精品。**英国住宅 IP 不等于都走 9929，线路差别可能非常大**，只能看商家自己怎么写。

### 3. 带宽与流量：直播和发图文不是一个量级

住宅 IP 云服务器带宽普遍不大，100Mbps 已经算主流配置，部分家宽产品能到 300M、500M。流量要看清是双向计费还是单向计费——双向计费意味着上传下载都扣额度。发图文、养号，1TB 一个月绰绰有余；做直播、频繁上传视频，流量消耗会比想象中快，2TB 起步更保险。

### 4. 解锁能力：用测试 IP 自己验，别信“解锁大部分本土应用”

TikTok、ChatGPT、Netflix、Gemini、Disney+ 能不能解锁，是检验住宅 IP 成色最直接的方式。商家页面通常只写一句“解锁主流流媒体”，具体到你要用的那个服务，只有自己拿测试 IP 跑一遍才算数。

### 5. 退款与换 IP：住宅 IP 有被墙的额外风险

这类产品有个机房 IP 没有的风险：IP 可能被墙或被封。所以退款窗口和换 IP 政策要先看清楚再付款，各家的差别非常大——有的 48 小时内可全额退款，有的 24 小时无理由但收手续费，还有的住宅产品**开通激活后直接不支持退款**。这一条比价格重要。

## 常见问题

**住宅 IP 和 VPN 有什么区别？**
VPN 是共享出口，多人复用同一批 IP，平台很容易识别为代理；住宅 IP 云服务器给的是独享 IP，整个 IP 只归你一个人用，纯净度和可控性都不是一个层级。

**双 ISP 比单 ISP 好在哪？**
双 ISP 意味着 IP 同时绑定两个不同运营商的网络，冗余度更高，被判定为机房 IP 的概率更低，稳定性也更好。代价是价格比单 ISP 贵。

**怎么验证商家给的是不是真家宽？**
三步：ipinfo.io 查 ASN 归属公司，scamalytics 查风险评分，pingip.cn 交叉验证。ASN 显示为当地宽带运营商、类型标 Residential 才算过；显示 Hosting 或 Data Center，就是机房 IP 换了说法。买之前先要测试 IP，买之后在退款窗口内复验一遍。

**刚开通 IP 就被墙了怎么办？**
先查 IP 是否在黑名单。丽萨主机的规则是开通 24 小时内、IP 在黑名单内可免费更换，超时更换收费。所以开通当天就该测，别拖到第二周才发现。

**年付还是月付？**
算账结论是年付更便宜，月均能再低 25% 左右；决策结论是先月付。IP 质量、线路晚高峰表现、解锁情况这三件事，只有跑起来才知道，用一个月换一次确认，比省下那 25% 更值。

**能支付宝付款吗？**
丽萨主机支持支付宝和 USDT。要注意 USDT 退款只退到账户余额，走支付宝退款路径更直接。

**原生 IP 能当住宅 IP 用吗？**
不能。原生只保证注册国和机房国一致，ASN 仍可能是云厂商。平台看的是 ASN，不是你页面上的“原生”两个字。
